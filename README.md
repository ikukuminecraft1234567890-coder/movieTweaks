## 🚀 なぜ movieTweaks なのか？（軽さの極限追求）

「ちょっと不要な部分を切り取りたいだけなのに、重い動画編集ソフトが起動するまで何十秒も待たされる……」  
「文字や四角で囲むだけなのに、巨大なソフトでPCのファンが唸る……」

**movieTweaks** は、そんなストレスを完全にゼロにするために設計されました。

| 項目 | 従来の一般的な動画編集ソフト / Electron製ツール | **movieTweaks** |
| :--- | :--- | :--- |
| **起動時間** | 5〜15秒以上 | **0.2 〜 0.4 秒（瞬時起動）** |
| **バイナリサイズ** | 150 MB 〜 数 GB | **約 300 KB**（フレームワーク依存） |
| **メモリ使用量** | 500 MB 〜 2 GB 超 | **最小クラス（ネイティブ最適化）** |
| **カット書き出し速度** | 再エンコードで数分 | **1〜3秒（無劣化ストリームコピー）** |
| **再生エンジン** | ソフトウェア / Webデコーダー | **OSネイティブ DXVA / Media Foundation (GPU負荷極小)** |

## ✨ 主な機能

### 1. ⚡ 超高速カット編集（無劣化ストリームコピー対応）
- **イン点（I）・アウト点（O）** のワンクリック設定で不要な区間を即座にトリミング。
- **分割（S）** でクリップを複数に分割可能。
- **無劣化カット出力 (`-c copy`)**: テキストや図形がない単純カット時は再エンコードを行わず、ストレージのI/O速度（数秒）で一瞬で出力完了！画質の劣化も一切ありません。

### 2. 📝 テキストオーバーレイ（テロップ・字幕入れ）
- 画面上へドラッグ＆ドロップで自由配置、リサイズ可能。
- フォントサイズ、文字色、**縁取り（アウトライン）**、背景色（テロッププレート風）、角丸、太字を細かくカスタマイズ。
- 日本語ネイティブIME入力に完全対応。

### 3. 🎨 図形オーバーレイ（四角形・円・矢印・直線）
- 注目させたい箇所を囲む矩形（四角）、楕円、矢印、直線をワンクリック追加。
- 枠線色、塗りつぶし色、線の太さ、角丸、不透明度を自在に調整。

### 4. 🖼 画像オーバーレイ（ステッカー・ロゴ配置）
- PNG, JPG, WebP, GIF などの画像ファイルをプレビュー画面にドラッグ＆ドロップするだけで即座に配置。
- アスペクト比を維持した拡大縮小、配置場所の移動、表示時間帯の調整。

### 5. ⏱ 直感的な軽量タイムライン
- 時間軸ルーラーと再生ヘッドによるスムーズなシーク・スクラブ。
- 動画クリップトラック（保持範囲・カット範囲の可視化）。
- オーバーレイトラック（テキストや図形の表示タイミングバーをドラッグでスライド移動・両端を伸縮）。

### 6. 🎬 FFmpeg 統合エクスポート
- テキスト・図形・画像がある場合は、プレビュー画面と1ピクセルの狂いもなく完全に合成して MP4 で書き出し。
- システムの FFmpeg を自動検出。未インストールの場合はワンクリックで自動セットアップ可能。

## ⌨️ キーボードショートカット

| キー | 動作 |
| :--- | :--- |
| `Space` | 再生 / 一時停止 |
| `◀` (Left) / `▶` (Right) | 1フレーム戻る / 1フレーム進む（コマ送り） |
| `Shift` + `◀` / `▶` | 1秒戻る / 1秒進む |
| `I` | 現在位置を **イン点（開始点）** に設定 |
| `O` | 現在位置を **アウト点（終了点）** に設定 |
| `S` | 現在位置でクリップを **分割（Split）** |
| `Delete` | 選択中のテキスト / 図形 / 画像を削除 |
| `Ctrl + O` | 動画ファイルを開く |
| `Ctrl + S` | プロジェクトを保存 (`.mtproj`) |

## 🛠 ビルドと実行方法

### 動作要件
- Windows 10 / 11 (x64)
- .NET 9.0 Runtime

### ビルド手順

```powershell
# リポジトリのクローン
git clone https://github.com/ikukuminecraft1234567890-coder/movieTweaks.git
cd movieTweaks

# ビルド
dotnet build MovieTweaks.sln -c Release

# 超軽量リリース版の発行（binaries are ~300KB!）
dotnet publish MovieTweaks\MovieTweaks.csproj -c Release -r win-x64 --no-self-contained -o publish

# 起動
.\publish\MovieTweaks.exe
```

### 単体テストの実行

```powershell
dotnet test MovieTweaks.sln
```
